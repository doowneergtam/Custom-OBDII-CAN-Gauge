# Decisions and overturned assumptions

| Date | Decision | Why |
|---|---|---|
| 2026-10-10 | ESP-IDF v5.5.5, not 6.0 | Waveshare BSP 3.0.1 and its LVGL 9 example are validated on 5.5.x; 6.0 has breaking changes and the BSP adds a `usb` dependency only for 6.x. Revisit for the P4 if 6.x gains something we need. |
| 2026-10-10 | Header pins are GPIO16/17/18 + GPIO43/44 (UART0) | Brief guessed GPIO1/2/3; those are the SD card pins per Waveshare hardware reference. |
| 2026-10-10 | CAN TX/RX on GPIO16/17, encoder on 18/43/44 | ROM bootloader logs on GPIO43 at every reset; keep that off the CAN transceiver. Console goes to USB-Serial-JTAG. |
| 2026-10-10 | Use the Waveshare BSP managed component rather than hand-rolled CO5300 init | Gets display, touch, PMIC, expander, brightness in one dependency. Wrap it in `hal_board` so the P4 build swaps it out. |
| 2026-10-10 | Encoder is an LVGL keypad indev, not the adapter's encoder indev | Rotation -> LV_KEY_LEFT/RIGHT, push -> LV_KEY_ENTER held for the real duration. Unambiguous with one focused object and works with rollers in menus. Built on the espressif/knob and espressif/button components the BSP already pulls in. |
| 2026-10-10 | Menu is a single roller whose options change per level | Fits a round 466 px face, one widget to style, encoder-native. Long press backs out. |
| 2026-10-10 | Alarms: on-screen channels sound, off-screen channels banner only | User rule. Every channel with a tone configured is watched; a tone plays only if that channel is in a visible cell, otherwise a 3 s banner names the channel and value. Bad zones repeat on an interval (default 10 s). |
| 2026-10-10 | Bar fill modes: gradient (default), segments, solid | Gradient: whole bar is one colour sampled from a smooth blend of the zone colours at the tip position (cheap in LVGL: one arc colour per frame). Segments: each slice its own zone colour. Solid: zone colour of the tip. |
| 2026-10-10 | Per-channel colour zones (cold/good/warn/bad) are user-editable, with range | Users have custom sensors; preset values are defaults only. Lives in config JSON per channel. |
| 2026-10-10 | Layouts are 1, 3, 4, 6, 7 | 2 and 5 never looked right on the round screen. 6 = centre + pentagon, 7 = centre + hexagon. |
| 2026-10-10 | Faces are custom-drawn (LVGL draw API in LV_EVENT_DRAW_MAIN), not widget trees | One object per cell, exact match to the browser preview, cheap segments/bands, no 54-arc widget trees. |
| 2026-10-10 | Config header is gauge_config.h | `config.h` resolved to another component's header on the include path. |
| 2026-10-12 | TWAI driver installed from a core-1 task with ESP_INTR_FLAG_LOWMED | First flash: "No free interrupt inputs for TWAI" on core 0, where the display, touch, I2S and I2C drivers hold the level-1 slots. |
| 2026-10-12 | Selection ring times out after 3 s; touch mirrors the encoder | User rule. Tap = select, tap again = reset min/max, hold = menu, swipe = move/scroll. |
| 2026-10-12 | Simulated data and data source (MegaSquirt / OBD-II) are runtime config, in the System menu and on the phone page | Firmware ships with sim on so the UI can be tested before the car; OBD-II poller gives the generic-CAN path. |
| 2026-10-12 | User colour presets and saved screens live in the config JSON (`theme_presets`, `screens`, max 8 each) | One list for the phone page and the gauge menu; a screen is layout + cells + theme only, zones and tones stay with the channel. Firmware keeps them as cJSON subtrees and re-uses the full parser to load one. |
| 2026-10-12 | Separate scalers: digits, labels, units, min/max, ring thickness, outer cells; per-channel show units/min/max | User request. All in `theme` except the show flags, which are per channel. |
| 2026-10-12 | LVGL draw buffers in internal DMA RAM (2 x 24 lines), not the BSP's 50-line PSRAM buffers; Wi-Fi buffer counts trimmed | With PSRAM buffers the SPI driver bounces every flush through a 46 KB internal buffer; after Wi-Fi start the largest free block was 36 KB and the screen froze with "Failed to allocate priv TX buffer". hal_board now replicates bsp_display_start() with its own buffer config. |
| 2026-10-12 | Hotspot on at boot (`wifi.on`), idle timeout default never; no credentials on screen | User preference. Menu entry and page switch persist the choice. |
| 2026-10-12 | No automatic text fitting; scalers go well past the screen (digits 500%, labels/units/minmax 400%, ring 300%, outer cells 250%) | User wants to size freely, even off the edge. Digits above 48 px come from Montserrat-Light.ttf (OFL) via TinyTTF in components/fonts, embedded 2026-10-12. |
| 2026-10-12 | LVGL uses the C library allocator (`CONFIG_LV_USE_CLIB_MALLOC`), `SPIRAM_MALLOC_ALWAYSINTERNAL=1024`, LVGL warnings on | TinyTTF glyphs at 100+ px overflowed LVGL's 64 KB built-in pool: digits vanished, stray "1"s. Now glyphs land in PSRAM. Baseline internal free 134 KB with Wi-Fi up. |
| 2026-10-12 | Serial console (`gauge_console`) + `tools/soak.py` for unattended testing | Overnight soak on flash 23: runs of 12 min, 30 min and 4 h (17,081 commands) all clean, no reboots, internal heap flat at 126-130 KB, low-water 40 KB during a Wi-Fi restart. |
| 2026-10-13 | Carrier rev B: Traco TSR 1-2450 for 5 V, WCMCU-230 (SN65HVD230) module in a 1x6 socket instead of a soldered TJA1051, HY2.0-5P car connector (LIGHTS, GND, CAN L, CAN H, 12V) and HY2.0-4P encoder connector, both on the rear face | User choice of parts; cables leave away from the screen. 1 A at 5 V covers the Waveshare's 250-400 mA with Wi-Fi peaks; 100 µF on the output. Module carries its own 120 Ω termination. |
| 2026-10-13 | Header pins re-assigned: CAN TX GPIO44, CAN RX GPIO43 via 1 kΩ, encoder A/B/push on 18/17/16 | The module's CTX/CRX sit directly above header pins 4/5, which made the single-sided carrier routable with no wire links. GPIO44 is an input during boot (recessive), GPIO43 carries the ROM boot log but only into our RX pin, through R3. Superseded the 2026-10-10 row above. |
| 2026-10-13 | Carrier routed by `hardware/pcb/router.py` (grid Dijkstra, best of N net orders) and checked by `drc.py` | Hand routing on a single layer kept crossing; the scripted router plus crossing/clearance check gives a verifiable result. 0.5 mm clearance on a 0.25 mm grid, 0.4 mm minimum accepted for milling. |
| 2026-10-16 | Carrier rev C: encoder dropped, two analog sensor inputs on GPIO17/18 (ADC2) with 1k/1k5 dividers and solder-jumper 1k pull-ups from 5 V; HY2.0-4P sensor connector (5V, GND, SENS1, SENS2); J2 reordered to GND, LIGHTS, CAN L, CAN H, 12 V | User wants two extra sensors and is happy to lose the knob (touch covers it). Pull-ups and jumpers on board were a user request. |
| 2026-10-16 | Rev C is two-layer with 9 rivet vias; clearance relaxed to 0.42 mm and 0603 parts in the sensor cluster | At 0.5 mm / 1206 the sensor network could not be routed on the 46 mm disc; user chose the finer rules over an off-board solution. Top tracks end only on axial leads, chip pads or vias (no plated holes). |
| 2026-10-16 | Analog inputs scaled by user calibration points (piecewise linear) entered in the sensor's own terms: volts for 0-5 V senders, ohms for resistive ones; the firmware undoes the carrier's divider and pull-up | Sender data sheets give volts or ohms against the measured quantity, so the user types those straight in. Table lives in config `aux`, edited on the phone page; on-device menu only lists enabled inputs. |
| 2026-10-16 | Knob driver compiled out by default (`CONFIG_NB1_ENCODER=n`) | Its GPIO17/18 pull-ups would load the analog inputs on the rev C carrier; touch covers every encoder action. |
| 2026-10-24 | Theme gets per-element switches and vertical offsets (digits, label, units, min/max, ring/track, ticks, needle, Stock reading backdrop), tick width/length/count sliders, needle width/length and hub size, sweep rotation; screen zoom 70-130% on the Screen tab; custom channel names; sliders carry 1-step arrows; the phone page shows only the controls the chosen style draws | User request after the first Stock-style photos. Saved screens snapshot the whole theme block, so all of it rides along. The Stock odometer-window backdrop is now off by default (the grey rectangle in the photos). The single-cell face radius went from 229 to 240 to fill the glass; the outer-cell scale no longer touches the single face. |
